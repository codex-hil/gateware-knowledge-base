# Gateware / FPGA IP Knowledge Base

Evidence-backed technical memory for reusable FPGA IP in MODULIQ, AI-HIL,
ARTIQ/quantum control, instrumentation and DSP projects.

The initial schema, tooling and inspected catalogue are being prepared in a draft PR.
Before implementing reusable gateware, search and evaluate existing upstream IP,
prefer suitable maintained and adequately verified implementations, and record
selection and rejection reasons.

Upstream source is referenced, not vendored. Upstream licenses remain applicable.
